# Description

An ongoing hobby lab and playground for experimenting with model routing, local inference, observability, vector search, databases, and Git workflows across local and hosted providers. I use it to explore new tools, learn how they behave in a self-hosted environment, and assemble useful developer infrastructure.

## Technologies

- Docker and Linux
- Open WebUI, OmniRoute, and CLIProxyAPI
- Forgejo
- PostgreSQL, Redis, and Valkey
- Qdrant and pgvector
