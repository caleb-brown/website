# Description

An AI orchestration workflow that coordinates multiple language models, gathers independent proposals and critiques, and selects results through ranked-choice voting.

## Highlights

- Parallel model execution with role-specific profiles
- Structured response parsing and failure handling
- Extensible workflow built for OpenAI-compatible model APIs

## Technologies

- Python
- FastAPI
- Pydantic
- asyncio
- Open WebUI
- OpenAI-compatible APIs
